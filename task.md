Project Overview: "TaskFlow" (Mini Issue Tracker) For an SDE 1 level live-coding interview (2–3 hours), the goal is to evaluate a candidate's grasp of foundational Next.js App Router, React state management, Route Handlers (API), basic database/in-memory operations, and clean component composition.  App Concept: A minimalist Jira/Trello-like board or issue tracker called TaskFlow.  Core Capabilities: Users can view a list of tasks, filter them by status, create a new task via a form, and update a task's status.  Tech Stack Expectations: Next.js (App Router, Server/Client Components), Tailwind CSS for styling, and an in-memory array or lightweight local store (e.g., Prisma with SQLite or standard JSON mock array) to simulate backend persistence.
